# 결정: 분류별 정상 빈 목록은 허용하고 전체 0건일 때 수집을 실패시킨다

- 상태: Accepted
- 결정일: 2026-10-23
- 범위: 계절학기 수집 오류 수정과 운영 대상 전환

## 문제와 근거

2026년 동기 계절학기 실제 조회에서 분류 1·2·5·7·3은 합계 86건, 분류 4는 오류 없는 빈 배열을 반환했다. 파서가 마지막 빈 분류를 C003으로 거부하여 앞서 조회한 강의까지 반영하지 못하는 문제를 재현했다. 건수는 점검 당시 측정값이다.

## 선택 기준과 대안

정상 강의 누락 방지, 실제 오류에 대한 기존 보호, 분류별 수동 예외 관리 최소화를 기준으로 비교했다. 빈 분류를 설정에서 제외하면 추후 해당 분류 강의가 누락될 수 있다. 오류 코드를 포괄적으로 무시하면 정상 빈 배열과 실제 오류의 구분이 흐려진다.

## 사용자 결정

1. 정상 `dsEstSbjList: []`는 빈 목록으로 반환하고 다음 분류 조회를 계속한다.
2. 전체 분류 합계가 0건이면 수집기의 기존 검증에서 C003으로 실패시킨다.
3. 통신·학교 오류 envelope·파싱·필수 정보·중복 오류는 계속 전체 수집 실패로 처리하고 기존 정상 데이터를 보존한다.
4. 실제 파서를 사용하는 단위 회귀 테스트를 추가하고 검증한다.
5. 수정본을 운영에 배포하고 기본 수집 대상을 `2026` / 동기 계절학기(`U211600025`)로 저장한 뒤 수집·검색·알림을 확인한다.

## 적용 범위와 제약

운영 실행 버전 `533a5cee54a9d1a1b0bddc7d105cf553000fa78d`에서 분기하여 수집 수정과 회귀 테스트만 적용한다. 별도로 진행 중인 개발 브랜치의 구조·기능 변경은 포함하지 않는다. 정상 빈 배열만으로 학교가 잘못 반환한 0건과 실제 미개설을 구분할 수 없다는 제약은 수용한다. 전체 0건 보호와 실제 오류 검증을 유지한다.

운영 검증에서는 공개된 강의 데이터와 로그인한 운영자 계정을 사용한다. 실제 알림 검증은 운영자 본인의 테스트 알림 경로를 우선 사용하며 일반 이용자 대상의 인위적인 여석 알림을 만들지 않는다.

## 배포 전 검증

운영 기준 코드에서 관련 8개 클래스의 단위 테스트 56건과 전체 PMD·Checkstyle 검사, `bootJar` 빌드가 통과했다. 수집기 테스트는 실제 파서를 사용하여 빈 분류의 6개 위치, 전체 0건과 정상 빈 분류 뒤의 실제 오류를 확인한다. 테스트는 DB·외부 API 없이 실행했다. 운영 적용·대상 전환·E2E 결과는 배포 후 별도 기록한다.
