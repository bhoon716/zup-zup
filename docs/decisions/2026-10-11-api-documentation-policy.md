# 결정: Swagger UI 문서 화면은 재설계에서 제외한다

- 상태: Accepted
- 결정일: 2026-10-11
- 범위: API 문서 화면의 제공 여부
- 대체 결정: 없음. 개발 환경에서만 제공하는 방식은 비교 제안이며 확정된 결정이 아니었음
- 관련 자료: `apps/server/build.gradle`, `apps/server/src/main/resources/application-prod.yml`

## 문제와 확인된 사실

API 주소·요청값·응답 형식을 확인하는 문서 화면의 접근 범위를 비교했다. 사용자는 해당 화면이 Swagger인지 확인하고 필요하지 않다는 의견을 밝혔다.

저장소에는 `springdoc-openapi-starter-webmvc-ui` 의존성이 있으며 운영 설정에서 Swagger UI와 API 명세 생성이 비활성화되어 있다. 이는 저장소 설정을 확인한 결과이며 실제 운영 서버를 조회한 결과는 아니다.

## 선택지와 결정

개발 환경에서만 제공, 운영 관리자에게도 제공, 외부 공개 방식을 비교한 뒤 사용자는 화면 자체를 제외하는 방향을 선택했다.

1. Swagger UI를 API 문서 화면으로 제공하는 기능은 재설계에서 제외한다. 개발·운영 환경의 문서 화면 제공이나 문서 화면용 관리자 접근 기능을 필수 범위로 두지 않는다.
2. 이번 선택은 문서 화면의 필요성에 관한 결정이다. OpenAPI 명세 생성·프론트엔드 연동과 문서 주석·의존성 전체의 제거 여부는 사용 관계를 확인하여 상세 설계에서 정한다. 화면 제외를 모든 API 계약 기록 폐기로 확대하지 않는다.

## 근거와 후속 논의

사용자가 문서 화면의 필요성이 낮다고 판단했다. 사용하지 않는 화면과 해당 화면의 접근 설정을 관리하는 부담을 줄인다.

실제 구현에서 Swagger UI 관련 의존성·설정·접근 허용 경로를 정리하고 다른 기능의 사용 관계를 확인한다. 이번 변경은 의사결정 기록이며 실제 의존성·코드·서버 설정 변경이나 테스트 실행은 하지 않았다.

## 재검토 조건

화면을 통한 API 확인이나 외부 개발자 지원이 실제로 필요해지면 다시 검토한다.

## 추가 결정: Springdoc 전체를 제거한다

- 결정일: 2026-10-12
- 상태: Accepted
- 사용자 선택: 전체 제거와 화면만 제거하고 명세 생성을 유지하는 방식을 비교한 뒤, 사용자가 `1 제거`를 선택했다.

Swagger UI 제외에 더해 OpenAPI JSON·YAML 자동 생성도 재설계 범위에서 제외한다. `springdoc-openapi-starter-webmvc-ui` 의존성과 해당 기능만을 위한 설정·접근 허용 경로·Swagger 문서 애너테이션을 제거하는 방향으로 확정한다.

프론트엔드와 CI의 확인한 경로에서는 생성 명세를 소비하는 흔적을 찾지 못했다. 사용하지 않는 명세 생성 기능과 문서 애너테이션을 관리하는 부담을 줄이는 것이 근거다. 저장소 밖의 소비자가 전혀 없다는 사실까지 확인한 것은 아니다. API 계약 기록은 필요한 문서와 테스트에서 관리하며, 이번 선택으로 요청 검증·인증·응답 동작을 변경하지 않는다.

구현 시 문서용 애너테이션과 실제 동작에 필요한 Spring·검증 애너테이션을 구분한다. 관련 보안 설정 및 문서 화면을 전제로 하는 테스트도 함께 정리한다. Commons Lang 등 함께 선언된 의존성은 별도 사용 관계를 확인하여 처리하고, 다른 의존성에 필요한 보안 버전 제약을 일괄 제거하지 않는다.

이번 추가는 제거 방침에 대한 의사결정 기록이다. Springdoc 관련 소스·의존성·설정의 실제 제거와 테스트 실행은 아직 진행하지 않았다.

## 구현 반영: MVC 폴더 정리와 함께 Swagger 전체 제거

- 반영일: 2026-10-13
- 사용자 요청: 코드에서 Swagger 관련 코드를 모두 제거한다.

1. Java 파일 77개의 Swagger 문서 애너테이션과 import를 제거한다. Spring MVC 매핑·검증·직렬화 애너테이션은 유지한다.
2. `springdoc-openapi-starter-webmvc-ui` 의존성, 운영 환경의 `springdoc` 비활성화 설정, Swagger UI·OpenAPI 문서 경로용 보안 규칙을 제거한다. H2 콘솔의 기존 관리자 제한은 유지한다.
3. Swagger 화면·명세가 존재함을 전제로 하던 기존 테스트와 설정 검증 항목을 정리한다. 테스트를 새로 추가하거나 실행하지 않는다.
4. README의 Swagger 제공 표기를 제거한다. 과거 의사결정 기록은 보존한다.
5. 소스에서 Commons Lang의 직접 사용이 확인되지 않아 Springdoc 옆에 명시했던 직접 의존성도 제거한다. 다른 라이브러리의 전이 의존성에 적용될 수 있는 기존 Commons Lang 보안 버전 제약은 유지한다.

업무 API의 요청·응답·권한 계약은 이번 제거로 변경하지 않는다. 메인 및 기존 테스트 소스의 컴파일로 연결을 확인한다.
