# 결정: 테스트용 dotenv를 제거하고 환경변수로 통일한다

- 상태: Accepted
- 결정일: 2026-10-12
- 범위: Java 테스트의 설정 입력과 dotenv 의존성

## 확인한 사실

`apps/server/build.gradle`은 `java-dotenv`를 테스트 의존성으로 선언하고 있다. Java 소스에서 확인한 사용처는 학교 API를 실제 호출하는 `JbnuCourseApiClientTest` 한 곳이며, API URL과 세션 초기화 URL을 읽는다. 해당 테스트에는 환경변수 조회와 기본 URL도 이미 있다.

## 대안과 결정

1. dotenv를 제거하고 환경변수로 통일한다.
2. 로컬 `.env` 파일을 편하게 읽기 위해 테스트 의존성을 유지한다.

사용자는 1번을 선택했다. Java 테스트에서 `java-dotenv` 의존성과 `Dotenv` 호출을 제거하는 방향으로 확정한다. 테스트 설정을 변경할 때는 터미널·IDE 등 실행 환경에서 환경변수를 제공한다. 현재 테스트의 기본 학교 URL은 별도 변경 요구가 없는 한 유지한다.

## 근거와 영향

사용처가 한 곳인 테스트 전용 라이브러리와 추가 설정 입력 경로를 줄인다. 로컬 실행자가 `.env` 파일만 만들어 두면 테스트가 자동으로 읽던 편의는 사라지므로 필요한 값을 실행 환경에 제공해야 한다.

배포에서 사용하는 `.env` 파일과 Compose 등의 환경변수 주입 방식은 이번 제거 대상이 아니다. 설정값이나 비밀정보를 소스에 하드코딩하는 방식으로 대체하지 않는다.

## 구현 상태와 재검토 조건

이번 변경은 의사결정 기록이며 실제 Gradle 의존성·테스트 코드 변경과 테스트 실행은 아직 진행하지 않았다. 여러 테스트의 로컬 설정 관리가 실제 부담이 되면 입력 방식과 도구 필요성을 다시 검토한다.
