# 전북대 강의 수집 HTTP 구간별 시간

2026-11-10 22:04 KST에 운영 호스트 `zupzup`에서 실제 JUMP 조회를 1회 재현했음. 비교 대상은 2026년 2학기, 분류 `1,2,5,7,3,4`임. 분류 사이 500 ms 대기를 다섯 번 적용했음. 앱의 기존 요청 인코더와 요청 헤더를 사용했고, 각 분류에서 새 curl 8.5.0 HTTP/1.1 클라이언트로 쿠키 GET과 강의 POST를 연달아 호출했음. 두 요청은 같은 연결과 쿠키 저장소를 사용했음. 앱의 JVM 내부 구간, JSON 파싱, DB 저장은 측정 범위 밖임.

## 관찰

- GET과 POST 12건 모두 HTTP 200이었고, 모든 POST에서 `dsEstSbjList` 배열을 확인했음. 리다이렉트와 재시도는 없었음. 연결은 GET에서만 새로 열렸고 POST는 6건 모두 재사용했음.
- HTTP 합계는 31.215초였음. 여기에 설정된 분류 간 대기 2.500초를 더하면 33.715초임. 클라이언트 프로세스 시작, 응답 검증 등 측정 범위 밖 시간은 이 합계에 포함되지 않음.
- POST가 HTTP 시간의 82.7%였음. POST 25.803초 중 첫 바이트까지가 16.220초, 이후 본문 수신이 9.583초였음. 분류 1·5가 POST 합계의 약 78%를 차지했음.
- 쿠키 GET의 연결 포함 합계는 5.411초였음. 연결의 DNS 시간은 첫 분류에서 379 ms였고, 나머지에서는 약 1 ms였음.
- `time_namelookup`, `time_connect`, `time_appconnect`, `time_starttransfer`, `time_total`은 curl write-out 지표를 사용했음. 이 결과는 한 사이클의 운영 호스트 네트워크 관측임. 앱의 JDK HTTP 클라이언트와 동일한 런타임 수치로 해석할 수 없음.
- 분류별 원시 지표와 실행 스크립트는 로컬 `.performance-results/jump-http-timing/`에 보관했음.

## 수집 한 사이클에서 연결·쿠키 재사용

같은 날 22:34~22:36 KST에 운영 호스트의 OpenJDK 21.0.13으로 기존 방식과 재사용 방식의 실제 JUMP 조회를 각각 1회 실행했음. HTTP/1.1, 2026년 2학기, 분류 순서 `1,2,5,7,3,4`, 분류 간 500 ms 대기, 기존 요청 인코더를 양쪽에 동일하게 적용했음. 기준은 분류마다 새 클라이언트와 쿠키 GET을 사용했고, 후보는 한 클라이언트와 쿠키 저장소를 공유했음. 두 시행 모두 GET·POST 200 응답을 받았고 6개 분류 모두 강의 행 수와 정렬된 강의 식별자 해시가 일치했음. 전체 시간에는 분류 간 대기, 클라이언트 생성·종료, 응답 형식과 식별자 검증이 포함됨. DB 저장은 포함하지 않음.

이번 한 쌍에서 전체 시간은 23.6% 짧았음. 재사용으로 GET과 TLS 핸드셰이크를 각각 5회 줄였음. POST 시간 차이는 응답 헤더 이후 본문 수신 구간에 집중됐으며, 1회씩 순서대로 실행했으므로 전체 시간 차이를 모두 세션 재사용 효과로 귀속할 수 없음.

`CourseCrawlFetcher`가 수집 시작 시 세션을 열어 모든 분류에 공유하고, 수집을 마치거나 실패하면 닫도록 변경했음. 분류 요청이 실패하면 해당 연결과 쿠키를 폐기해 기존 재시도 한도와 대기 안에서 실패한 분류를 새 세션으로 요청함. 분류 순서, 분류 간 대기, gzip 처리, 본문 크기 제한, 오류 분류를 유지함. 로컬 HTTP 통합 테스트는 동일 수집에서 TCP 포트·쿠키가 공유되는지, 다음 수집에 새 세션을 여는지, 후속 분류 HTTP 503 후 실패한 분류만 새 세션에서 재시도하는지 검증함. 운영 서버의 측정은 별도 프로브로 수행했음.

JFR 집계, 분류별 원시 지표와 프로브 소스는 `.performance-results/jump-session-reuse/`에 보관했음.

Reader 실험본이 있던 상태에서 크롤러 범위 테스트 89개와 서버 `check`를 통과했음. 2026-11-11에 파서 변경과 실험용 테스트를 되돌린 뒤 서버 `check`를 다시 통과했으며 최종 테스트는 621개임. 파서 후보별 측정과 제외 근거는 [파서 실험 기록](2026-11-10-jbnu-course-parser.md)에 정리했음.
