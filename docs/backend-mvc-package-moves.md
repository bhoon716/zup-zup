# 백엔드 MVC 패키지 이동 목록

- 기준: `7149c32b`에서 기능별 MVC 폴더로 정리한 뒤 추가 요청에 따라 저장소 통합과 Swagger 제거를 반영했다.
- 기능별로 `entity`, `controller`, `repository`, `service`를 구분한다.
- 요청 DTO 24개는 `dto/request/`, 응답 DTO 38개는 `dto/response/`에 두고 내부 공유 데이터 타입은 `dto/`에 유지한다.
- 중복 JPA 저장소 25쌍과 단일 구현의 조회 계약 두 곳을 통합했다. 기존 쿼리·잠금·DB 구조·업무 로직은 유지한다.
- Swagger 문서 애너테이션·의존성·설정·전용 경로 및 이를 전제로 하던 기존 테스트를 제거했다.
- 과거 의사결정의 기존 코드 경로는 아래 이동 목록으로 대응한다. 저장소 통합으로 여러 기존 경로가 하나의 파일을 가리킬 수 있다.

## 기존 테스트 소스

메인 코드와 같은 역할 패키지로 기존 테스트의 package·import를 정리했다. 저장소 통합에 맞춰 기존 저장소 테스트 네 파일의 이름과 타입 참조를 변경했다. 테스트 케이스를 추가하거나 실행하지 않았다. Swagger 제공을 전제로 하던 기존 테스트만 제거·정리했다.

## 빈 폴더

이동·통합 및 이전 구현 취소 뒤 남은 빈 프로젝트 폴더를 삭제했다. Git 내부와 무시된 빌드·도구·의존성 폴더는 제외했다.
